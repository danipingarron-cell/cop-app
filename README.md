# Plantilla COP

App para rellenar el control COP (PRC-08.02) desde el móvil y generar el Word.

Se abre en https://danipingarron-cell.github.io/cop-app/ y se puede instalar en el móvil (icono en la pantalla de inicio). Funciona sin conexión. Los COP que se rellenan se guardan solo en el móvil donde se hacen; aquí no se sube ningún dato.
